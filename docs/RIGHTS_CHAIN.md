# Hetu 权利链协议（Rights Chain v0.1）

## 意向许可

- 全树意向许可：**MIT**（开源发布准备状态；正式许可文本见仓库根 LICENSE）。
- LICENSE 版权行：`Copyright (c) 2026 HongYun.dev`。**2026-11-24 维护方裁定**：HongYun.dev 为维护方个人所有域名，版权主体即域名持有人（自然人），个人持有版权合法，无需法人实体；LICENSE 行维持现状即为最终落名。

## 贡献者权利链（MIT + 非独占 CLA 路线）

- 贡献者**保留版权**；通过签署 CLA 授予项目方不可撤销的：使用、修改、分发、
  约定条件下的再许可授权，以及必要的专利授权。
- CLA 为正式签署流程（电子签），不是 CONTRIBUTING 里的一句话默认条款。
- 员工/外包：雇佣/委托合同中须含工作成果知识产权归属或同等授权条款。
- AI 辅助生成代码：必须记录输入来源（提示词、参考材料），确认不含上游受保护表达；
  记录写入 `docs/evidence/ai-provenance/`。

## 依赖政策

- 运行时零第三方依赖（Python stdlib + SQLite）。任何新增依赖须先过权利链与许可证
  审核（仅接受 MIT/BSD/Apache-2.0 类宽松许可），并更新 PROVENANCE.md 依赖清单。
